# Pilot changes

The six existing pregnancy-tracker guides now explain setup, week-by-week use, date corrections, the post-birth transition, public tools and free/Premium access. These are localized from the approved English source at `4f1fbdae4`, using the evidence register.

| Language | Previous guide title | Current guide title |

| fa | «مسیر روزانه»: راهنمایی متناسب با مرحلهٔ شما | اپلیکیشن بارداری BeMama: راهنمای مسیر روزانه |
| ar | «المسار اليومي»: إرشاد مُصمَّم حسب مرحلتك | تطبيق متابعة الحمل BeMama: دليل الرحلة اليومية |

| pt | A Jornada Diária: orientação sob medida para a sua fase | Aplicativo de gravidez BeMama: guia da jornada diária |

The previous localized guides were general descriptions of the daily journey. The revised guides explain what readers can do and link to the corresponding tools with descriptive text in the same language. The existing six-section structure and the source image position are preserved.

The calculator now uses native app/calculator vocabulary in its title, summary and controls. French weeks are explicitly labeled SA; Portuguese introduces DPP with its full meaning; Persian and Arabic explain Gregorian date entry. The calculation, trimester timeline and input methods are unchanged. A visible explanation now identifies the 40-week convention used for a known due date.

A Chrome review found a missing space after the author name in the new Turkish byline. The renderer now preserves the suffix space for custom bylines, and a regression check covers it.

This is stronger coverage of two existing page intents. It is not a claim that every selected word was absent elsewhere on the site. No keyword-density target, new route per synonym or new raster image was introduced.
